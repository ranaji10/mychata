---
name: task-brief
description: Write a MyChata task brief in docs/tasks/ from a request. Use before starting any implementation so scope, allowed files and acceptance checks are explicit.
---

Use `docs/tasks/_TEMPLATE.md`. Keep it under 60 lines. Exact file paths in "Files allowed". Acceptance = commands or test names. Link at most five context files. If the request conflicts with an ADR in `docs/decisions/`, say so first. Put questions only a human can answer at the end.
