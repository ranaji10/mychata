| ID                  | Finding                                                                                                                                                                                                                                                                                                                                                    | Done                                                                                                                                                                                                                                                                                                                 |

| F-30 (security)     | Every page view sent the whole address to Google as `page_location`. An e-mail link (confirm address, reset password) comes back as `/auth#access_token=…&refresh_token=…`, so Google got live sign-in tokens; public calendar, manual, request-form, guest and invitation tokens went the same way.
