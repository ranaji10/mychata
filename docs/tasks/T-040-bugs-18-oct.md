## What the recordings showed

- Bug 3 (Android): every save in the HAR reached the database and succeeded (201/204). The console shows `NotFoundError: Failed to execute 'removeChild'` right after the refresh that follows a save, and the HAR shows `translate.googleapis.com` calls: Chrome's page translation was on and broke React's updates, so the error screen took over. The same translation turned the initials "RD" into "Family house" (bug 14a).
- Bug 3 (iPhone): `TypeError: Load failed` is Safari's network error for the first request on a connection the phone dropped while idle.
- The HAR also holds a password typed during the test (bug 15). It stays outside the repo; delete it after use.
